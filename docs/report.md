# 调研报告

随着人工智能技术的发展，AI聊天机器人（Chatbot）在日常生活和工作场景中的应用日益广泛。然而，当前主流的 Chatbot 交互模式仍以“线性问答”为主——即用户提出一个问题，系统返回一个回答，后续对话依赖于上下文的连续堆叠。这种模式存在信息冗余、逻辑跳跃、缺乏结构化表达等问题。

为探索更高效、更具思维延展性的 AI 交互方式，结合原型系统“BrainTree”的初步实践，整理出以下调研结果。

“BrainTree”的初步实践的功能：
- 采用“思维导图式”的交互模型，将每个问题与回答作为独立节点，构建非线性知识网络。
- 节点化交互结构
- 每个新问题和对应的回答构成一个新的“节点”。
- 新节点仅继承从根节点到当前路径的历史上下文（即父系路径），兄弟节点不参与上下文构建。

这样可以避免因并行分支导致的信息混乱，同时保留逻辑主线清晰。

## 调研内容

### 人物 A 

>感觉可以结合rag来做，比如可以算sentence embedding。个人比较关键的问题是得到几个回答之间的父子关系，比如因果关系，然后构建一个这种图。又或者用户在问新问题的时候也可以去用rag搜索到哪些之前回答的内容与这个问题最相关，然后展示出来。

- 引入 RAG 技术增强关联性，用户提问时，系统可通过 RAG（Retrieval-Augmented Generation）检索历史回答中与当前问题最相关的内容。展示这些相关内容作为参考或推荐，帮助用户发现已有答案中的潜在联系。
- 语义嵌入（Sentence Embedding）用于关系识别，使用 sentence embedding 技术计算问题之间的语义相似度，判断是否属于同一主题或子话题。
可辅助判断父子关系、因果关系等逻辑结构。
- 构建知识图谱式对话结构
目标是形成一个可可视化、可追溯的“智能思维导图”，实现多维度的知识组织。用户不仅能看到当前回答，还能看到该问题在整个认知网络中的位置。

关键挑战

如何准确判定“兄弟节点”之间的相关性？是否应基于问题关键词、语义向量还是用户意图？

需要建立一套自动化的逻辑推理机制来推断节点间的因果/层级关系。

## 总结

目前我们是通过手动创建的方式管理各个对话节点，然而，调研指出用户似乎更倾向于原本的自动对话，然后进行思维导图的总结，最后以思维导图的形式总结这个对话。

用户还需要一个更方便检索问题的功能。当用户键入新的提问信息时，检索历史回答中与当前问题最相关的内容。展示这些相关内容作为参考或推荐；或者是使用 sentence embedding 等技术计算问题之间的语义相似度，判断是否属于同一主题或子话题。
